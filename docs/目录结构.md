# CF优选目录结构

## 正式内容

- `src/`：Python 源码；`update.py` 是 CLI 兼容入口，`gui_redesign.py` 是新版 GUI。
- `tests/`：单元、集成、e2e 和 GUI 测试。
- `packaging/`：PyInstaller spec、`assets/icons/` 图标资源与桌面快捷方式维护脚本。
- `dist/`：当前正式 CLI/GUI exe，仅保留最后一版。
- `_cf_run/`：程序运行数据、缓存和结果，不纳入版本控制。
- `.github/`：CI 测试工作流（`test.yml`）。
- `README.md`、`BUILDING.md`、`ITERATION_LOG.md`：使用、构建和迭代说明。
